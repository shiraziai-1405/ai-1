# Shirazi AI Telegram Bot 🤖

این پروژه یک ربات تلگرامی هوش مصنوعی است که با استفاده از **Cloudflare Workers**، **AvalAI API** و **Cloudflare D1** ساخته شده است.

## 📱 تجربه ساخت
این پروژه در کانال تلگرامی [ربات سازان تجربی](https://t.me/shiraziai_1405) مستندسازی می‌شود و تمام مراحل ساخت به صورت تجربی به اشتراک گذاشته می‌شود.

## ⚙️ امکانات
- دریافت و پاسخ به پیام‌های متنی
- دریافت و تحلیل عکس‌ها (Vision)
- پاسخ به فایل‌ها (متن)
- دیتابیس ذخیره کاربران و لاگ‌ها (D1)
- تنظیمات کاملاً داینامیک با config.json (بدون هاردکد)

## 🚀 راه‌اندازی
1. ریپازیتوری را در Cloudflare Workers متصل کنید.
2. متغیرهای محیطی (Secrets) را در کلودفلر تنظیم کنید:
   - TELEGRAM_BOT_TOKEN
   - AVALAI_API_KEY
   - WEBHOOK_SECRET
   - CONFIG_URL (لینک Raw فایل config.json در گیت‌هاب)
3. دیتابیس D1 را بسازید و schema.sql را روی آن اجرا کنید.
